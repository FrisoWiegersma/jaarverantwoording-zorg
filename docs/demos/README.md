# README demos

Recorded from the running app in Chromium with `codex-browser`, using public DigiMV data for Stichting Basalt (28099814) and Stichting Treant Zorggroep (01170406).

| Clip | Workflow | Duration |
| --- | --- | --- |
| `organisation-profile` | Search → profile → read chart years → inspect revenue source | 16 seconds |
| `organisation-comparison` | Add Treant → compare yearly figures → inspect consolidated revenue source | 17 seconds |

The clips use a 1440 × 1080 desktop viewport in the light theme. Idle and loading time is trimmed; each clip ends with a held screenshot of its source panel. GIF previews are 800 × 600 and loop silently. MP4 versions use H.264 with the metadata at the start for browser playback. These are edited demonstrations, not performance measurements.

To refresh them, follow those workflows in the real app, capture only the page, and retain the reporting year, units, and consolidation labels. Keep each GIF below 5 MB. No browser chrome, account details, or synthetic figures belong in these assets.
